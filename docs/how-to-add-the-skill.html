Skill setup guide

Adding the MISRA Guidelines skill

A step-by-step procedure for installing the MISRA C:2023 & C++:2023 reference skill so Claude picks it up automatically when you review or write C/C++ code.

skill name: misra-guidelines entry: SKILL.md no build step

Before you start

What a "skill" is

A Claude skill is just a folder containing a SKILL.md file with a YAML frontmatter (name + description) and any supporting files. Claude reads the description to decide when to load it — you don't call it manually. This skill's folder looks like this:

misra-guidelines/ ├── SKILL.md # entry point + router (must exist) ├── c/ # MISRA C:2023 bundle │ ├── overview.md │ ├── directives.md │ └── rules/ # rules grouped by section └── cpp/ # MISRA C++:2023 bundle ├── overview.md └── rules/
Prerequisite: Claude Code (CLI, desktop, or web), or any Agent SDK setup that supports skills. Nothing to compile or install as a package — skills are plain Markdown.

Installation

Pick one of the three methods below depending on whether you want the skill for yourself, for a repository, or shared through a plugin.

1 Method A · Personal

Install as a personal skill (available in every project)

Copies the skill into your user-level skills directory so Claude Code can use it in any repo on your machine.

# from the root of this repository
mkdir -p ~/.claude/skills
cp -R misra-guidelines ~/.claude/skills/

# verify it landed
ls ~/.claude/skills/misra-guidelines/SKILL.md
2 Method B · Project

Install as a project skill (shared with your team via git)

Lives inside a target repository under .claude/skills/ and is committed, so every collaborator gets it automatically.

# inside the repo you want MISRA checks in
mkdir -p .claude/skills
cp -R /path/to/misra-guidelines .claude/skills/

git add .claude/skills/misra-guidelines
git commit -m "Add MISRA guidelines skill"
Recommended for teams. Committing under .claude/skills/ means MISRA guidance travels with the codebase and stays version-controlled alongside it.
3 Method C · Plugin

Distribute through a plugin marketplace (optional)

For sharing across many repos or an organization. Package the skill inside a plugin and publish it to a marketplace your team has configured.

# place the skill under a plugin's skills/ directory
your-plugin/
└── skills/
    └── misra-guidelines/ # (this folder)

# then, in Claude Code
/plugin marketplace add <your-marketplace>
/plugin install <your-plugin>
4 Verify

Confirm Claude can see the skill

Reload skills (restart Claude Code, or start a new session), then check it's listed and trigger it.

# list available skills in Claude Code
/skills

# you should see:
misra-guidelines  Reference index of MISRA C:2023 and C++:2023…

Then just ask a question that matches its description — Claude loads the skill on its own:

  • "Does this function comply with MISRA C Rule 15.7?"
  • "Review this C++ file against MISRA C++:2023."
  • "What category is Dir 4.12 and why does it exist?"

How it behaves once installed

  • Claude reads SKILL.md first, then loads only the relevant section file (e.g. c/rules/12-16-expressions-and-control.md) — keeping context lean.
  • C and C++ are separate bundles; a C rule number does not map to the same C++ number.
  • Summaries are paraphrased (MISRA text is copyrighted). Entries marked ⚑verify should be checked against the official standard before use in a formal compliance matrix.
Troubleshooting. If the skill doesn't appear: confirm SKILL.md sits at the folder's top level, that its frontmatter has both name: and description:, and that you started a fresh session after copying the files.
